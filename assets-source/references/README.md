# Toxic Teddies · Set 1 expression sheets

Reviewed five-expression reference sheets for the 41 distinct Set 1 character designs. A/B names are aliases for the same design.

Progress: **20 of 41 sheets**, containing **100 of 205 expressions**.

Expression order: Neutral, Evil Grin, Gross, Angry, Maniacal Laugh. Each source PNG is preserved at its original dimensions and bytes.

See [set-1-manifest.json](set-1-manifest.json) for names, aliases, dimensions, sizes and SHA-256 checksums.

The [original Toxic Toby sheet](style-reference/toxic-toby-original.png) is retained as a style reference and is excluded from completed-sheet totals.

These are character-production reference sheets. They are not integrated into the game or deployment.
